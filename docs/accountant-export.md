# คู่มือส่งข้อมูลให้สำนักงานบัญชี

ระบบส่งข้อมูลออกให้นักบัญชีดูได้ 2 ทาง — ดาวน์โหลดไฟล์ และซิงก์เข้า Google Sheets

---

## หลักการที่ต้องเข้าใจก่อน

**ข้อมูลไหลทางเดียว: ระบบ → ไฟล์/Google Sheets**

ระบบส่งออกไปให้ดูเท่านั้น ถ้านักบัญชีแก้ตัวเลขในไฟล์หรือใน Sheets
จะ **ไม่** ย้อนกลับเข้าระบบ และจะถูกเขียนทับในการซิงก์รอบถัดไป

เหตุผล: Google Sheets บังคับให้เดบิตเท่ากับเครดิตไม่ได้ · ป้องกันการแก้ย้อนหลังไม่ได้ ·
ไม่มีบันทึกว่าใครแก้อะไร — ถ้าดึงกลับเข้าระบบจะทำลายความถูกต้องที่ฐานข้อมูลปกป้องไว้

**ขั้นตอนที่ถูกต้องเมื่อนักบัญชีเจอที่ผิด**

1. นักบัญชีแจ้งกลับมาว่าใบไหนผิด
2. ผู้บันทึกแก้ในระบบด้วยการ **กลับรายการ** แล้วบันทึกใหม่ให้ถูก
3. ซิงก์อีกครั้ง ตัวเลขใน Sheets จะตรงกับระบบทันที

---

## รายงานที่ส่งออก 9 ชุด

| แท็บ | เนื้อหา | นักบัญชีใช้ทำอะไร |
|---|---|---|
| สมุดรายวัน | ทุกใบสำคัญ แยกรายบรรทัด พร้อมผู้บันทึกและผู้อนุมัติ | ตรวจการลงบัญชี ทำงบการเงิน |
| งบทดลอง | ยอดยกมา เคลื่อนไหว คงเหลือ ทุกบัญชี | ปิดงบ ตรวจความสมดุล |
| รายงานภาษีขาย | ตามแบบประกาศอธิบดี มีเลขผู้เสียภาษีและสาขา | ยื่น ภพ.30 |
| รายงานภาษีซื้อ | แยกภาษีซื้อต้องห้ามไว้แล้ว | ยื่น ภพ.30 |
| หัก ณ ที่จ่าย-เราหัก | หนังสือรับรองที่เราออกให้ผู้ขาย | ยื่น ภงด.3 / ภงด.53 |
| หัก ณ ที่จ่าย-ถูกหัก | ภาษีที่ลูกค้าหักเราไว้ | เครดิตภาษีตอนยื่น ภงด.50 |
| ลูกหนี้คงค้าง | รายใบพร้อมจำนวนวันเกินกำหนด | ตรวจยอด ตั้งค่าเผื่อหนี้สงสัยจะสูญ |
| เจ้าหนี้คงค้าง | รายใบพร้อมวันครบกำหนด | ตรวจยอด |
| ผังบัญชี | รหัสและชื่อบัญชีทั้งหมด | อ้างอิง |

ส่งออกเฉพาะรายการที่ **ลงบัญชีแล้ว** เท่านั้น ใบร่างไม่ถูกส่ง

## วิธีที่ 1 — ดาวน์โหลดไฟล์ (ใช้ได้ทันที)

**เมนู:** ตั้งค่า → ส่งข้อมูลให้นักบัญชี

| ปุ่ม | ได้อะไร |
|---|---|
| **ดาวน์โหลด Excel ทุกรายงาน** | ไฟล์เดียวมีครบ 9 แท็บ จัดรูปแบบตัวเลขและตรึงหัวตารางให้แล้ว |
| **CSV** ข้างแต่ละรายการ | แยกไฟล์ทีละรายงาน |

**ส่งให้นักบัญชีได้ 2 แบบ**

- แนบไฟล์ Excel ส่งอีเมลไปเลย
- อัปโหลดไฟล์ Excel ขึ้น Google Drive แล้วเปิดด้วย Google Sheets — จะได้ครบทุกแท็บเหมือนกัน

> ไฟล์ CSV ใส่ BOM ไว้แล้ว เปิดใน Excel ภาษาไทยไม่เพี้ยน

## วิธีที่ 2 — ซิงก์เข้า Google Sheets อัตโนมัติ

### ตั้งค่าฝั่ง Google ครั้งเดียว ประมาณ 10 นาที

1. เข้า [Google Cloud Console](https://console.cloud.google.com) สร้างโปรเจกต์ใหม่ (ฟรี)
2. ค้นหา **Google Sheets API** แล้วกด **Enable**
3. ไปที่ **IAM & Admin → Service Accounts → Create service account** ตั้งชื่ออะไรก็ได้
4. เปิด Service Account ที่สร้าง → แท็บ **Keys** → **Add key → Create new key** → เลือก **JSON**
   จะได้ไฟล์ `.json` ดาวน์โหลดมา
5. สร้าง Google Sheet เปล่าขึ้นมาหนึ่งไฟล์ กด **แชร์** ใส่อีเมลของ Service Account
   (หน้าตาเป็น `ชื่อ@โปรเจกต์.iam.gserviceaccount.com`) ให้สิทธิ์ **ผู้แก้ไข**

### ตั้งค่าในระบบ

**เมนู:** ตั้งค่า → ส่งข้อมูลให้นักบัญชี → เชื่อมต่อ Google Sheets

- วาง **ลิงก์ Google Sheet** ทั้งอันได้เลย ระบบตัดเอาเฉพาะรหัสให้เอง
- เปิดไฟล์ JSON ด้วย Notepad คัดลอกทั้งไฟล์มาวาง
- เลือกขอบเขต: ทั้งปีบัญชี หรือเฉพาะงวดล่าสุด
- กด **ทดสอบการเชื่อมต่อและบันทึก** — ระบบจะลองเชื่อมจริงก่อน ถ้าไม่ผ่านจะไม่บันทึกให้

### สั่งซิงก์

- กดปุ่ม **ซิงก์เดี๋ยวนี้** เมื่อไหร่ก็ได้
- แต่ละแท็บถูก **ล้างแล้วเขียนใหม่ทั้งแผ่น** เพื่อให้ตัวเลขตรงกับระบบเสมอ ไม่มีของค้าง
- ประวัติการซิงก์ทุกครั้งถูกบันทึกไว้ดูย้อนหลังได้

### ตั้งเวลาซิงก์อัตโนมัติ

ในหน้าเดียวกันมีคำสั่งพร้อมโทเคนให้คัดลอก เอาไปใส่ Task Scheduler บน Windows
หรือ cron บนเซิร์ฟเวอร์ แนะนำวันละครั้งตอนกลางคืน

```bash
curl -X POST "http://localhost:3100/api/export/sync" -H "X-Export-Token: <โทเคน>"
```

## ข้อควรระวัง

**คีย์ Service Account ถูกเก็บในฐานข้อมูล** — ใครอ่านฐานข้อมูลได้จะเขียน Google Sheet นั้นได้ด้วย
ใช้ Service Account ที่แชร์เฉพาะไฟล์นี้ไฟล์เดียว **อย่าให้สิทธิ์ระดับโปรเจกต์**

**ข้อมูลส่วนบุคคลออกไปอยู่ที่ Google** — ชื่อลูกค้า เลขประจำตัวผู้เสียภาษี ที่อยู่
ตาม PDPA ควรจำกัดสิทธิ์การเข้าถึงชีตเฉพาะนักบัญชีที่เกี่ยวข้อง
**อย่าตั้งเป็น "ทุกคนที่มีลิงก์"**

**ขีดจำกัดของ Google Sheets** — 10 ล้านเซลล์ต่อไฟล์ SME ทั่วไปใช้ได้หลายปี
ถ้าใกล้เต็มให้แยกไฟล์ตามปีบัญชี โดยสร้างการเชื่อมต่อใหม่ชี้ไปไฟล์ใหม่

**เฉพาะผู้จัดการบัญชีเท่านั้นที่ตั้งค่าได้** ส่วนการดาวน์โหลดไฟล์ทำได้ทุกบทบาทที่ดูรายงานได้

## แก้ปัญหา

| ข้อความ | สาเหตุ | วิธีแก้ |
|---|---|---|
| **ไฟล์ Service Account ไม่ใช่ JSON ที่ถูกต้อง** | คัดลอกไม่ครบ | เปิดไฟล์ .json คัดลอกทั้งไฟล์รวมวงเล็บปีกกา |
| **ขอสิทธิ์จาก Google ไม่สำเร็จ (400) account not found** | Service Account ถูกลบ หรือ key เก่า | สร้าง key ใหม่แล้ววางใหม่ |
| **Google ปฏิเสธการเข้าถึง (403)** | ยังไม่ได้แชร์ Sheet ให้ Service Account | เปิด Sheet → แชร์ → ใส่อีเมล Service Account เป็นผู้แก้ไข |
| **ไม่พบ Google Sheet ตามรหัสที่ระบุ (404)** | ID ผิด หรือไฟล์ถูกลบ | วางลิงก์ Sheet ใหม่ทั้งอัน |
| **ขอสิทธิ์ไม่สำเร็จ — API ยังไม่เปิด** | ยังไม่ได้ Enable Google Sheets API | เข้า Cloud Console เปิดใช้งาน API |
| ซิงก์ผ่านแต่ Sheet ว่าง | ยังไม่มีรายการที่ลงบัญชีแล้ว | บันทึกเอกสารก่อน ใบร่างไม่ถูกส่งออก |
