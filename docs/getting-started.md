# คู่มือเริ่มต้นใช้งาน — ฉบับเข้าใจง่าย

ระบบบัญชีคู่สำหรับธุรกิจบริการ · อ่านจบใน 5 นาที · ใช้งานได้ทันที

---

## 1. เปิดระบบ

**ต้องมีอย่างเดียว:** Docker Desktop เปิดอยู่

เปิด PowerShell ที่โฟลเดอร์นี้ แล้วพิมพ์

```bash
docker compose up -d --build
```

ครั้งแรกรอประมาณ 3 นาที ครั้งต่อไปแค่ไม่กี่วินาที

เสร็จแล้วเปิดเบราว์เซอร์ไปที่ **http://localhost:3100**

ระบบมาแบบ**ว่างเปล่า** มีแต่ผังบัญชีมาตรฐาน 79 บัญชี ไม่มีข้อมูลสมมติใด ๆ

---

## 2. ติดตั้งครั้งแรก

ครั้งแรกที่เปิด ระบบจะพาไปหน้าติดตั้งอัตโนมัติ กรอก 2 ขั้นตอน

**ขั้นที่ 1 — ข้อมูลกิจการ**
ชื่อกิจการ · เลขประจำตัวผู้เสียภาษี · รหัสสาขา · ที่อยู่ · **วันเริ่มต้นปีบัญชี**
(ระบบสร้างงวดบัญชี 12 งวดให้เอง รอบบัญชีไม่ตรงปีปฏิทินก็ได้)

**ขั้นที่ 2 — ผู้ดูแลระบบคนแรก**
ชื่อผู้ใช้ · ชื่อ-นามสกุล · รหัสผ่าน — บัญชีนี้ได้บทบาทผู้จัดการบัญชี ทำได้ทุกอย่าง

> ⚠️ **จดรหัสผ่านไว้ให้ดี** ระบบยังไม่มีฟังก์ชันลืมรหัสผ่าน

### หลังติดตั้ง — ตั้งค่าอีก 3 อย่างจึงจะออกเอกสารได้

แดชบอร์ดจะขึ้นเช็กลิสต์บอกว่าเหลืออะไรบ้าง กดปุ่ม "ตั้งค่า" ข้างรายการได้เลย

| ต้องมี | เมนู |
|---|---|
| บัญชีธนาคารอย่างน้อย 1 บัญชี | ตั้งค่า → บัญชีธนาคาร |
| ลูกค้าอย่างน้อย 1 ราย | ตั้งค่า → ลูกค้าและผู้ขาย |
| ผู้ขายอย่างน้อย 1 ราย | ตั้งค่า → ลูกค้าและผู้ขาย |

เมื่อครบแล้วเช็กลิสต์จะหายไปเอง และเริ่มออกใบแจ้งหนี้ได้ทันที

**ก่อนกรอกข้อมูลบัญชีจริง** อ่าน [production-checklist.md](production-checklist.md) ให้ครบก่อน

---

### อยากดูตัวอย่างก่อนใช้จริง

ถ้าต้องการชุดสาธิตที่มีข้อมูลตัวอย่าง 2 เดือนและผู้ใช้ทดลอง 5 บทบาท ใช้คำสั่งนี้แทน

```bash
docker compose -f docker-compose.yml -f docker-compose.demo.yml up -d --build
```

รหัสผ่านทุกบัญชีทดลองคือ `Demo@2569` · ใช้กับฐานข้อมูลใหม่เท่านั้น
ถ้าเคยเปิดระบบไปแล้วต้อง `docker compose down -v` ก่อน

**ห้ามใช้ชุดสาธิตกับข้อมูลจริงของกิจการ**

## 3. ให้คนอื่นเปิดดูด้วย

`localhost` เปิดได้แค่เครื่องตัวเอง ถ้าจะให้คนอื่นดูต้องเลือกวิธีตามนี้

### ดูสถานะและลิงก์ทั้งหมด

```bash
.\share.ps1
```

สคริปต์จะบอกว่าตอนนี้ใครเข้าได้บ้าง และลิงก์คืออะไร

---

### วิธีที่ 1 — คนในออฟฟิศเดียวกัน (ง่ายที่สุด)

เหมาะกับ: นั่งประชุมกันอยู่ ต่อไวไฟวงเดียวกัน

**ทำครั้งเดียว** เปิด PowerShell แบบ **Run as Administrator** แล้วพิมพ์

```bash
.\share.ps1 -OpenFirewall
```

จากนั้นให้คนอื่นเปิดลิงก์ที่สคริปต์บอก เช่น `http://192.168.1.27:3100`

| ข้อดี | ข้อเสีย |
|---|---|
| ตั้งค่าครั้งเดียว ไม่ต้องลงโปรแกรมเพิ่ม | ต้องอยู่วงเครือข่ายเดียวกัน |
| เร็ว ไม่ผ่านอินเทอร์เน็ต | เลข IP เปลี่ยนได้เมื่อย้ายเครือข่าย |

**ปิดเมื่อเลิกใช้**

```bash
.\share.ps1 -CloseFirewall
```

---

### วิธีที่ 2 — คนอยู่คนละที่ แต่รู้จักกัน (แนะนำ)

เหมาะกับ: ลูกค้าอยู่คนละจังหวัด · ทีมทำงานที่บ้าน

เครื่องคุณติดตั้ง **Tailscale** ไว้แล้ว ใช้ได้เลย

1. ให้อีกฝ่ายติดตั้ง Tailscale จาก [tailscale.com/download](https://tailscale.com/download)
2. เชิญเขาเข้า network ของคุณ (Tailscale admin → Invite)
3. ส่งลิงก์ที่ขึ้นต้นด้วย `http://100.` ตามที่ `share.ps1` แสดง

| ข้อดี | ข้อเสีย |
|---|---|
| ปลอดภัย เข้ารหัสตลอดทาง | อีกฝ่ายต้องลงโปรแกรม |
| ไม่ต้องเปิดพอร์ตออกอินเทอร์เน็ต | ต้องเชิญเข้า network ทีละคน |
| เฉพาะคนที่คุณเชิญเท่านั้นที่เข้าได้ | |

---

### วิธีที่ 3 — ใครก็ได้ที่มีลิงก์

เหมาะกับ: ส่งลิงก์ให้ลูกค้าดูเอง ไม่อยากให้เขาลงโปรแกรม

ใช้ **Cloudflare Tunnel** จะได้ลิงก์ https ฟรี ไม่ต้องสมัครสมาชิก

**1. ติดตั้ง** (ครั้งเดียว)

```bash
winget install --id Cloudflare.cloudflared
```

**2. เปิด tunnel** (เปิดค้างไว้ตลอดที่ต้องการให้เข้าได้)

```bash
cloudflared tunnel --url http://localhost:3100
```

จอจะขึ้นลิงก์แบบ `https://xxxx-xxxx.trycloudflare.com` — ส่งลิงก์นั้นให้ลูกค้าได้เลย

**3. ถ้ากดปุ่มบันทึกแล้วขึ้น "Invalid Server Actions request"**

ปกติไม่เจอ แต่ถ้าเจอ ให้แก้ `docker-compose.yml` ตรง `args:` ใส่โดเมนที่ได้มา (ไม่ต้องมี `https://`)

```yaml
    build:
      context: ./web
      args:
        ALLOWED_ORIGINS: "xxxx-xxxx.trycloudflare.com"
```

แล้ว **build ใหม่** (ค่านี้ถูกฝังตอน build เปลี่ยน environment เฉย ๆ ไม่มีผล)

```bash
docker compose up -d --build web
```

| ข้อดี | ข้อเสีย |
|---|---|
| อีกฝ่ายแค่คลิกลิงก์ | **ใครมีลิงก์ก็เข้าได้ทั้งหมด** |
| เป็น https เข้ารหัสให้อัตโนมัติ | ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่ |
| ไม่ต้องเปิดพอร์ตในไฟร์วอลล์ | ต้องเปิดหน้าต่างค้างไว้ |

> ⚠️ **สำคัญมาก** หน้าเข้าสู่ระบบแสดงรหัสผ่านทดลองไว้ ใครเปิดลิงก์ก็เข้าใช้และแก้ข้อมูลได้
> ใช้กับข้อมูลสาธิตเท่านั้น **ห้ามใส่ข้อมูลจริงของกิจการเด็ดขาด**
> ถ้าไม่อยากให้เห็นรายชื่อบัญชี ให้แก้ `DEMO_MODE: "false"` ใน `docker-compose.yml`
> ปิด tunnel ทันทีเมื่อสาธิตเสร็จ (กด Ctrl+C)

## 4. ใช้บนมือถือ

ระบบออกแบบให้ใช้บนมือถือเป็นหลัก ไม่ใช่แค่ย่อหน้าจอคอมพิวเตอร์ลงมา

| บนมือถือจะเป็นแบบนี้ | |
|---|---|
| **แถบเมนูล่าง** | 5 ปุ่มหลัก กดถึงงานที่ใช้บ่อยได้ในนิ้วเดียว |
| **เมนูเต็มอยู่ในปุ่ม ☰** | มุมซ้ายบน แตะแล้วเลื่อนออกมาจากข้าง |
| **ตารางกลายเป็นการ์ด** | ไม่ต้องเลื่อนซ้ายขวา ทุกช่องมีป้ายกำกับว่าเป็นตัวเลขอะไร |
| **ฟอร์มเรียงเป็นบล็อก** | ช่องกรอกเต็มความกว้าง แตะง่าย ไม่ต้องซูม |
| **ปุ่มบันทึกลอยอยู่ล่างจอ** | ไม่ต้องเลื่อนลงสุดเพื่อกดบันทึก |

### ขั้นตอนให้ลูกค้าเปิดบนมือถือ

1. ทำตาม[ข้อ 3](#3-ให้คนอื่นเปิดดูด้วย) เลือกวิธีแชร์ให้เรียบร้อยก่อน
2. ส่งลิงก์ให้ลูกค้าทางไลน์หรือแชต
3. ลูกค้าแตะลิงก์ แล้วเข้าสู่ระบบตามปกติ

> **มือถือเปิด `localhost:3100` ไม่ได้** เพราะ localhost หมายถึงตัวเครื่องมือถือเอง
> ต้องใช้ลิงก์ที่ขึ้นต้นด้วย `192.168.` หรือ `100.` หรือลิงก์ tunnel เท่านั้น

### ติดตั้งเป็นแอปบนหน้าจอโฮม

ใช้งานได้เหมือนแอปจริง เปิดเต็มจอ ไม่มีแถบเบราว์เซอร์

| เครื่อง | วิธีทำ |
|---|---|
| **iPhone (Safari)** | แตะปุ่มแชร์ ⌷ ด้านล่าง → เลื่อนหา **"เพิ่มไปยังหน้าจอโฮม"** → เพิ่ม |
| **Android (Chrome)** | แตะจุดสามจุดมุมขวาบน → **"เพิ่มลงในหน้าจอหลัก"** หรือ **"ติดตั้งแอป"** |

## 5. ลองใช้งาน 10 นาที

ทำตามนี้จะเห็นภาพว่าระบบทำงานอย่างไร

**① ดูภาพรวม** — เข้าด้วย `somchai` ดูแดชบอร์ด สังเกตป้ายเขียว **"ระบบสมดุล"** มุมบนซ้าย
ระบบตรวจความถูกต้องของตัวเลขให้ทุกครั้งที่เปิดหน้า ถ้าเพี้ยนแม้บาทเดียวจะเป็นสีแดง

**② ออกใบแจ้งหนี้** — รายรับ → ใบแจ้งหนี้ → + ออกใบแจ้งหนี้
กรอกค่าบริการ 100,000 บาท กดบันทึก แล้วคลิกเลขที่ใบสำคัญคอลัมน์ขวาสุด
จะเห็นว่าระบบลงบัญชีให้เองครบทุกบรรทัด

**③ ดูจุดที่คนทำผิดกันบ่อย** — ไปที่ รายงาน → รายงานภาษี
จะเห็นว่ายอดภาษีขาย **ยังไม่ขึ้น** ทั้งที่เพิ่งออกใบแจ้งหนี้
เพราะธุรกิจบริการเสียภาษีตอน**รับเงิน** ไม่ใช่ตอนวางบิล — ระบบจัดการให้ถูกต้องอัตโนมัติ

**④ รับเงินบางส่วน** — รายรับ → รับชำระเงิน → เลือกใบเมื่อกี้ แล้วแก้ยอดให้เหลือครึ่งเดียว
ดูว่าระบบคำนวณภาษีหัก ณ ที่จ่าย 3% จากยอดก่อน VAT และโอนภาษีขายตามสัดส่วนให้พอดี

**⑤ ลองทำให้พัง** — ไปที่ บัญชี → สมุดรายวัน เปิดใบไหนก็ได้
จะเห็นว่า**ไม่มีปุ่มแก้ไข** มีแต่ "กลับรายการ" เพราะบัญชีที่ลงแล้วห้ามแก้ตามหลักการตรวจสอบ

**⑥ ลองสลับบทบาท** — ออกจากระบบ เข้าใหม่ด้วย `owner`
เมนู "สร้างใหม่" จะหายไปหมด ลองพิมพ์ URL ตรงไปที่ `/invoices/new` ก็จะโดนปฏิเสธ

## 8. แก้ปัญหา

| อาการ | ทำอย่างไร |
|---|---|
| เปิด localhost:3100 ไม่ได้ | พิมพ์ `docker compose ps` ต้องขึ้น `healthy` ทั้งสองบรรทัด · ถ้ายังไม่ขึ้นให้รออีกสักครู่ |
| **เครื่องอื่นเปิดไม่ได้** | ยังไม่ได้เปิดไฟร์วอลล์ — รัน `.\share.ps1 -OpenFirewall` แบบ Run as Administrator |
| **ล็อกอินแล้วเด้งกลับหน้าเดิม** | เกิดเมื่อเปิดผ่าน https แต่ตั้งค่าไม่ตรง — ตรวจว่า `SESSION_COOKIE_SECURE` เป็น `auto` |
| **กดปุ่มบันทึกแล้วไม่มีอะไรเกิดขึ้น** | เปิดผ่าน tunnel แต่ยังไม่ได้ใส่โดเมนใน `ALLOWED_ORIGINS` (ดูข้อ 3 วิธีที่ 3) |
| พอร์ต 3100 ชนกับโปรแกรมอื่น | แก้เลขหน้าใน `docker-compose.yml` บรรทัด `"0.0.0.0:3100:3100"` เป็นเลขอื่น |
| ลืมรหัสผ่านที่ตั้งใหม่ | `docker compose down -v` แล้วเปิดใหม่ (ข้อมูลหายหมด กลับไปใช้ `Demo@2569`) |
| **มือถือเปิดลิงก์ไม่ได้** | ห้ามใช้ `localhost` บนมือถือ ต้องใช้ลิงก์ `192.168.` / `100.` / tunnel · และต้องเปิดไฟร์วอลล์ก่อน |
| **มือถือตัวหนังสือเล็กมาก** | เป็นอาการของเวอร์ชันเก่า ให้ `docker compose up -d --build` เพื่ออัปเดต |
| อยากเริ่มใหม่หมด | `docker compose down -v` แล้ว `docker compose up -d --build` |

## 9. สิ่งที่ต้องรู้

**ชุดนี้เป็นชุดสาธิต ไม่ใช่ระบบพร้อมใช้งานจริง**

- ข้อมูลทั้งหมดเป็นบริษัทสมมติ "เดโม คอนซัลติ้ง จำกัด"
- รหัสผ่านแสดงอยู่บนหน้าเข้าสู่ระบบ
