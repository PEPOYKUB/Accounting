# ติดตั้ง Docker Desktop

Docker Desktop เป็น**โปรแกรมเดียว**ที่ต้องติดตั้งก่อนใช้ระบบบัญชี
ไม่ต้องลงฐานข้อมูล ไม่ต้องลงโปรแกรมอื่นอีกเลย ทำครั้งเดียวจบ

ใช้เวลาประมาณ 15-25 นาที รวมเวลารีสตาร์ตเครื่อง

---

## ก่อนเริ่ม — เครื่องต้องได้ตามนี้

| ข้อ | ต้องมี | ตรวจอย่างไร |
|---|---|---|
| **Windows** | Windows 11 หรือ Windows 10 (64-bit) รุ่น 2004 ขึ้นไป | กด <kbd>Win</kbd>+<kbd>R</kbd> พิมพ์ `winver` แล้ว Enter |
| **แรม** | อย่างน้อย 8 GB (4 GB พอใช้ได้แต่จะช้า) | คลิกขวาที่ปุ่ม Start → ระบบ |
| **พื้นที่ว่าง** | อย่างน้อย 10 GB ในไดรฟ์ C | เปิด This PC ดูที่ไดรฟ์ C |
| **สิทธิ์** | ต้องเป็น Administrator ของเครื่อง | ถ้าเป็นเครื่องบริษัท อาจต้องให้ฝ่าย IT ติดตั้งให้ |
| **อินเทอร์เน็ต** | ใช้เฉพาะตอนโหลดตัวติดตั้ง | หลังติดตั้งเสร็จ ระบบบัญชีทำงานได้โดยไม่ต้องต่อเน็ต |

> **เรื่องค่าใช้จ่าย** Docker Desktop ใช้ฟรีสำหรับกิจการขนาดเล็ก
> (พนักงานน้อยกว่า 250 คน **และ** รายได้ต่อปีน้อยกว่า 10 ล้านดอลลาร์สหรัฐ)
> กิจการทั่วไปในไทยเข้าเกณฑ์ฟรีเกือบทั้งหมด ถ้าไม่แน่ใจให้ตรวจเงื่อนไขล่าสุดที่เว็บ Docker

---

## ขั้นที่ 1 — ดาวน์โหลด

เข้าเว็บ **[docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)**

กดปุ่มดาวน์โหลดสำหรับ **Windows** แล้วเลือกให้ตรงกับเครื่อง

- เครื่องทั่วไป (Intel / AMD) → เลือก **AMD64** หรือ **x86_64**
- เครื่องที่ใช้ชิป ARM เช่น Snapdragon → เลือก **ARM64**

> ไม่แน่ใจว่าเครื่องเป็นแบบไหน: คลิกขวาปุ่ม Start → ระบบ → ดูหัวข้อ "ชนิดระบบ"

ไฟล์ที่ได้ชื่อประมาณ `Docker Desktop Installer.exe` ขนาดราว 500-700 MB

---

## ขั้นที่ 2 — ติดตั้ง

1. **ดับเบิลคลิก** ไฟล์ที่ดาวน์โหลดมา
2. ถ้ามีหน้าต่างถามสิทธิ์ผู้ดูแล ให้กด **Yes**
3. หน้าตัวเลือกการติดตั้ง — **ติ๊กให้ครบทั้งสองข้อ** แล้วกด OK

   - `Use WSL 2 instead of Hyper-V` — จำเป็น
   - `Add shortcut to desktop` — สะดวกเวลาเปิดใช้

4. รอจนขึ้นว่าติดตั้งเสร็จ ใช้เวลาประมาณ 5-10 นาที
5. กด **Close and restart** เครื่องจะรีสตาร์ต

---

## ขั้นที่ 3 — เปิดใช้ครั้งแรก

หลังเครื่องบูตกลับมา

1. เปิด **Docker Desktop** จากไอคอนบนเดสก์ท็อป หรือพิมพ์หาในเมนู Start
2. หน้าข้อตกลงการใช้งาน — อ่านแล้วกด **Accept**
3. ถ้าถามให้ **สมัครสมาชิกหรือเข้าสู่ระบบ** → **ข้ามได้** กด Skip หรือ Continue without signing in
   (ระบบบัญชีไม่ต้องใช้บัญชี Docker)
4. ถ้าถามว่าจะใช้งานแบบไหน เลือกอะไรก็ได้ หรือกดข้าม

**รอจนไอคอนรูปวาฬ 🐳 มุมขวาล่างข้างนาฬิกาหยุดขยับ**

- วาฬขยับอยู่ = กำลังเริ่มทำงาน ยังใช้ไม่ได้
- วาฬนิ่ง = พร้อมใช้งาน

ครั้งแรกอาจใช้เวลา 2-5 นาที

---

## ขั้นที่ 4 — ตรวจว่าใช้ได้จริง

เปิดหน้าต่าง Docker Desktop ขึ้นมา ถ้าเห็นข้อความ **Engine running** สีเขียวมุมซ้ายล่าง แปลว่าเรียบร้อย

**ถึงตรงนี้ Docker พร้อมแล้ว** กลับไปทำต่อที่ [อ่านก่อน.md](../อ่านก่อน.md) ขั้นที่ 2
คือดับเบิลคลิก `ติดตั้ง.bat` ในโฟลเดอร์ระบบบัญชี

---

## ตั้งค่าเพิ่มอีกอย่างเดียว — เปิดเองตอนบูตเครื่อง

ถ้าไม่ตั้งข้อนี้ ทุกครั้งที่เปิดเครื่องใหม่จะต้องเปิด Docker Desktop เองก่อน ระบบบัญชีถึงจะใช้ได้

1. เปิด Docker Desktop
2. กดรูป **เฟือง** (Settings) มุมขวาบน
3. หน้า **General** ติ๊ก **Start Docker Desktop when you sign in**
4. กด **Apply & restart**

> ⚠️ **ข้อจำกัดที่ต้องรู้** Docker จะเริ่มทำงานก็ต่อเมื่อ**มีคนล็อกอินเข้า Windows แล้ว**เท่านั้น
> ถ้าไฟดับแล้วเครื่องบูตกลับมาค้างที่หน้าใส่รหัส Windows ระบบบัญชีจะยังไม่ขึ้น
> ต้องมีคนไปล็อกอินที่เครื่องก่อน

---

## ติดปัญหา

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| **WSL 2 installation is incomplete** | เปิด PowerShell แบบ Run as Administrator แล้วสั่ง `wsl --update` จากนั้นรีสตาร์ตเครื่อง |
| **Virtualization is not enabled** หรือ **Hardware assisted virtualization is not available** | ต้องเปิด Virtualization ใน BIOS ของเครื่อง ดูหัวข้อถัดไป |
| ติดตั้งแล้วแต่ **วาฬขยับไม่หยุด** เกิน 10 นาที | คลิกขวาไอคอนวาฬ → Quit Docker Desktop แล้วเปิดใหม่ · ถ้ายังไม่หาย ให้รีสตาร์ตเครื่อง |
| **ไม่มีสิทธิ์ติดตั้ง** / ถูกฝ่าย IT บล็อก | ต้องให้ฝ่าย IT ติดตั้งให้ แจ้งเขาว่าใช้ Docker Desktop with WSL 2 backend |
| ติดตั้งแล้ว `ติดตั้ง.bat` ยังบอกว่า **ไม่พบ Docker** | Docker Desktop ยังไม่ได้เปิด หรือยังเริ่มไม่เสร็จ · เปิดโปรแกรมรอจนวาฬนิ่งแล้วลองใหม่ |
| เครื่องอืดมากหลังลง Docker | เปิด Settings → Resources แล้วลด Memory ลงเหลือ 2-4 GB |

### วิธีเปิด Virtualization ใน BIOS

ตรวจก่อนว่าปิดอยู่จริงไหม — กด <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Esc</kbd> เปิด Task Manager
ไปแท็บ **ประสิทธิภาพ** → **CPU** ดูบรรทัด **การจำลองเสมือน** ถ้าขึ้นว่า **ปิดใช้งาน** ต้องไปเปิดใน BIOS

1. รีสตาร์ตเครื่อง แล้วกดปุ่มเข้า BIOS ตอนเครื่องเพิ่งเริ่มบูต
   (แล้วแต่ยี่ห้อ ส่วนใหญ่เป็น <kbd>F2</kbd> <kbd>F10</kbd> <kbd>Del</kbd> หรือ <kbd>Esc</kbd>)
2. หาเมนูชื่อ **Virtualization Technology**, **Intel VT-x**, **AMD-V** หรือ **SVM Mode**
   มักอยู่ในหมวด Advanced หรือ CPU Configuration
3. เปลี่ยนเป็น **Enabled**
4. กดบันทึกแล้วออก (ปกติคือ <kbd>F10</kbd>)

> ถ้าไม่ถนัดเรื่อง BIOS แนะนำให้ช่างคอมหรือฝ่าย IT ทำให้ การตั้งค่าผิดใน BIOS ทำให้เครื่องบูตไม่ขึ้นได้

## คำถามที่มักถามกัน

**Docker คืออะไร ทำไมต้องลง**
เป็นตัวห่อโปรแกรมให้ทำงานได้เหมือนกันทุกเครื่อง ระบบบัญชีกับฐานข้อมูลถูกบรรจุไว้ในนี้แล้ว
ทำให้ไม่ต้องไล่ติดตั้งฐานข้อมูลและตั้งค่าทีละอย่างเอง

**ต้องต่ออินเทอร์เน็ตตลอดไหม**
ไม่ต้อง ใช้เฉพาะตอนโหลดตัวติดตั้ง Docker ครั้งเดียว
ตัวระบบบัญชีอยู่ในไฟล์ `accounting-images.tar` ในโฟลเดอร์ที่ได้รับมาแล้ว

**ข้อมูลบัญชีเก็บไว้ที่ไหน**
อยู่ในเครื่องนี้เครื่องเดียว ไม่ได้ส่งขึ้นคลาวด์ ไม่ได้ส่งให้ Docker
จึงต้อง**สำรองข้อมูลทุกสัปดาห์แล้วคัดลอกออกไปเก็บที่อื่นด้วย**

**ถ้าลบ Docker ทิ้ง ข้อมูลหายไหม**
หาย ก่อนลบต้องสำรองข้อมูลด้วย `สำรองข้อมูล.bat` และคัดลอกไฟล์ออกไปเก็บที่อื่นก่อนเสมอ

**ต้องเปิดเครื่องทิ้งไว้ตลอดไหม**
ถ้าใช้คนเดียวที่เครื่องนี้ ไม่ต้อง เปิดตอนจะใช้ก็พอ
แต่ถ้าให้คนอื่นหรือมือถือเข้ามาใช้ เครื่องนี้ต้องเปิดและล็อกอิน Windows ค้างไว้
